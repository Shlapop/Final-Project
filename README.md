На руском
Экологический Telegram-бот
1.Описание
Этот Telegram-бот создан для повышения осведомлённости об экологических проблемах и предоставления полезных советов пользователям. Бот помогает людям задуматься о состоянии окружающей среды и предлагает простые шаги, которые каждый может предпринять, чтобы помочь планете.

2.Какие у бота функции
- `/start` — приветствие и инструкция по использованию бота
- `/hello` — дружеский ответ
- `/fact` — случайный экологический факт (без повторений)
- `/help_ecology` — случайный совет по защите окружающей среды
- `/restart` — перезапускает список фактов, если они закончились

3.Пример фактов и советов
Примеры фактов:
- "За последние 140 лет среднегодовая температура повысилась примерно на 1°С."
- "К 2050 году изменение климата может затронуть 1,5 миллиарда человек."

Примеры советов:
- "Экономьте энергию дома."
- "Ходите пешком, ездите на велосипеде или пользуйтесь общественным транспортом."
